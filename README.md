# 🧪 Automação de Testes E2E com Cypress

Bateria de testes automatizados para validação do site [Nome do Site].

## 🛠️ Tecnologias Utilizadas
- [Node.js](https://nodejs.org/)
- [Cypress](https://www.cypress.io/)

## 🚀 Como executar o projeto

1. Clone este repositório:
   `git clone https://github.com/seu-usuario/seu-repositorio.git`
2. Instale as dependências:
   `npm install`
3. Para rodar os testes em modo interativo (com interface gráfica):
   `npx cypress open`
4. Para rodar os testes em modo headless (sem interface, ideal para CI/CD):
   `npx cypress run`
